This release contains some minor fixes regarding the Explorer; it now allows the user to create and switch between multiple worlds.

# Release v0.0.2
After a good deal of work, I finally got something I can ship bps without feeling like it has no features. Since the previous release, the Graph now works properly with scrolling capabilities. The Inspector and Explorer now shows information and nodes/worlds, respectively. The timeline in the toolbar can be scrubbed to navigate the equation throughout time.

For more details on changes in this release and how to run, check out the release on GitHub.

# Release v0.0.1:
Just a minor release to test the GitHub Actions runner works properly. Right now, bps contains a very basic (and most likely broken at edge cases) equations parser and the beginnings of the files for rendering. Swing is the GUI framework for this since it's the one that I have the most experience in. Java is being used as the language because it's familiar to me and the performance bar is quite low for this program.

For more details on changes and how to run, check out the release on GitHub.
